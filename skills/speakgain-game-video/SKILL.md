# SpeakGain Game Video

ゲームの台詞を見せ、その同じ英文をSpeakGain画面と採用済みの声で練習する短尺動画を作る。既存部品を優先し、素材準備・有料音声生成・動画編集を分離する。

## 最初に読むもの

制作手順・採用設定・素材一覧の正本：[references/production.md](references/production.md)。手順はこのskillと一緒にdotfilesで管理し、メディアはGoogle Driveに保存する。

作業前に全文を読む。そこから、対象の素材manifest、音声記録、画角・編集設定を必要に応じて開く。ユーザーが別の制作ルートを指定した場合は、そのルートの手順書を優先する。

- このskillは手順書を同梱するが、メディア・APIキーは同梱しない。別端末では正本に記載したContentルートをその端末のDriveマウント先へ読み替える。素材にアクセスできない場合は場所の提供を求め、この会話を知っている前提で埋め合わせない。
- Google Driveは `SpeakGain/Content/library/skyrim` が既存素材庫、`SpeakGain/Content/projects/<投稿ID>` が投稿成果物の保存先。移行時のMovies内の控えを現在の正本と混同しない。具体的なパスと移行対象外の元動画は正本を確認する。
- ユーザーの今回の指示を優先する。正本の既定値は成功例であり、明示的な実験を妨げない。
- 過去のREADME・attempt記録は作成時点の履歴。現在の承認状態は正本を確認する。

## 依頼された範囲だけ進める

素材選定だけ、音声生成だけ、結合だけ、手順確認だけ、といった依頼を区別する。skillの起動を全工程の実行許可と扱わない。

1. **部品を確認する。** 原文・ゲーム切り抜き・SpeakGainスクショ・採用音声をフレーズIDで対応付け、既存ファイルと承認状況を確認する。
2. **不足部分を用意する。** 切り抜き、スクショ、音声を別ファイルに保存する。同じ英文の採用音声があれば再利用する。
3. **選んだ順序で組み立てる。** 導入に続き「ゲーム → 同じフレーズのSpeakGain画面」を繰り返す。基本3組、5組なども可能。完成尺は部品から算出する。
4. **検証して納品する。** 新バージョンとして書き出し、仕様・全編デコード・場面境界・音声の対応を確認する。指定の納品先がある場合だけコピーし、コピー一致を検証する。

全動画制作を依頼されたら、候補や計画だけで完了とせず、実ファイルの書き出しまで進める。ユーザー判断・アクセス・権限不足で止まるときは、できた範囲と具体的な不足を伝える。

## 素材選定と再利用

- 短くても難語・聞き慣れない表現・有名なmemeなど、学びや口にしたくなる要素がある台詞を選ぶ。別々の人物・場面を優先する。
- 字幕や文字起こしは候補探しに利用し、最終原文・語頭・語尾・実況の被りは元映像と照合する。
- ゲームは元画角版を残し、縦動画用の拡大版を別に保存する。拡大率はシーンごとに判断し、台詞字幕を切らない。
- スクショは対象カードの生成完了と原文を確認して取得する。動きが不要なら静止画を使い、音声変更だけで再録画しない。
- 長尺・20時間版は新しい素材元であり、新しい編集方式ではない。入手済み動画を先に使う。大容量ダウンロードは容量・通信状況・依頼範囲を確認して実行する。
- ダウンロード済みでも再利用許諾済みとは限らない。出典と未確認の利用条件を記録する。

## 音声と編集の重要事項

- 現在の採用声は **Weathered Warrior**。正本からVoice ID・モデル・設定を取得する。Voice Designを毎回やり直さない。
- 有料生成は不足音声に限定する。既存MP3を正本とし、再編集ではAPIを呼ばない。再生成時の演技・尺の完全一致を保証しない。
- APIキーはローカルの指定された認証ファイルから読み込み、skill・ログ・コマンド引数・納品物へ含めない。
- 結果不明のタイムアウトやエラーで無条件再送しない。残高不足時に勝手な入金・プラン変更・プロバイダー変更をしない。
- SpeakGain表示尺は、音声の実測尺＋前後余白からフレーム単位で算出する。3組から5組に増やしても完成秒数を手で固定しない。
- ゲームの元音声を保持し、SpeakGain画面部分だけ採用音声を使う。旧アプリ音声入りMP4を使うときは二重音声を防ぐ。
- 正本にある5秒導入、余白、音量、出力設定を出発点とする。過去動画の固定秒数・クロップ・フィルターを異なる素材へそのまま適用しない。
- 動画の音声差し替えと、SpeakGainアプリのTTS移行は別タスク。動画編集の依頼でアプリを変更しない。動画用の声が現行アプリに搭載済みとも案内しない。

## 完了時に残すもの

- 選択順、原文、出典・切り出し位置、使用したゲーム／スクショ／音声の対応。
- 新規生成した場合のVoice ID・モデル・設定・生成結果。編集時の画角、音量、尺、出力仕様。
- 完成ファイルへのリンク、実測の動画尺、確認結果、残る未確認事項。
- 実際のユーザー試聴承認があれば記録する。デコードや波形一致を聴感・台本一致の確認と混同しない。

このskillは制作手順の入口であり、汎用自動結合ツールではない。利用可能なスクリプトや素材は正本で確認し、存在しない自動化を案内しない。
